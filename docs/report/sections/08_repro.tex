\section{Reproducibility and disclosures}\label{sec:repro}

The code is at \url{https://github.com/stanley1208/paiec-2026} under the MIT license; it needs Python 3.13 and the packages pinned in \texttt{requirements.txt}, and the submission itself uses only the standard library. Appendix~\ref{app:repro} lists the commands that rebuild Tables~\ref{tab:data} to~\ref{tab:formative}, the figure and the final zip. The LLM ratings and guesses are released with the scripts that requested them, so every experiment reruns without an API key except two whose scripts were not kept: the embedding test and the scenario analysis behind V1's $\lambda = 0.5$. The hosted runs cannot be rerun exactly (Section~\ref{sec:llm}), and the formative feedback is private; the repository holds only the per-upload aggregates of Table~\ref{tab:formative}.

\paragraph{Compute and cost.}
All experiments ran on the CPU of one laptop (Intel Core Ultra 9 185H, 16 GB of memory); none used its GPU. The longest run, the V5 test, took about 15 minutes with three worker processes. The offline API calls cost an estimated \$14.26 (\$12.08 for the ratings, \$1.37 for the check of subject strength and \$0.80 for the guesses, each rounded), estimated from token counts at list prices, plus a few cents of live tests.
