\section{Reproduction}\label{app:repro}

\texttt{scripts/download\_data.py} fetches measurement-db at revision \texttt{bc8204d8} and records each file's SHA-256 hash; the loader checks the files against them on every load, and each results folder records the hashes, the commit and the package versions of its run, so a fresh download can be compared with the committed runs. \texttt{scripts/report\_tables.py} rebuilds Table~\ref{tab:data}, and \texttt{scripts/report\_results.py} rebuilds Tables~\ref{tab:offline} and~\ref{tab:formative} and Figure~\ref{fig:budgets} from the saved runs; each script named in Appendix~\ref{app:rules} reruns its test. For the two LLM checks, \texttt{results/llm\_rating/analyze.py} and \texttt{check.py --analyze} rescore the saved replies, while \texttt{rate.py} and \texttt{check.py --run} request new ones and need a key. \texttt{scripts/run\_zip\_check.py} runs the packaged V4 and V5 folders through the harness with cached replies. \texttt{scripts/export\_version5.py} followed by \texttt{scripts/build\_submission.py} rebuilds the keyless final zip byte for byte (SHA-256 \texttt{b7357ae7\ldots}) on Windows and Linux; the uploaded copy differs only by the key file that \texttt{scripts/add\_api\_key.py} adds.
